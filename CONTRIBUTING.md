# Questions and reproducibility reports

Thank you for using these neutron-star g-mode data.

For a reproduction problem, open an issue with:

- The release version or commit and your operating system/Python version.
- The exact command and the relevant error message.
- Whether dependency installation and input verification completed.

Do not include passwords, access tokens, private paths or unpublished research.
For questions about model assumptions or units, identify the figure, table or
dataset and consult the manual, data dictionary and paper first.

Documentation fixes are welcome as pull requests. Changes to published data
must be discussed and independently checked; do not change checksums merely
to make a modified input pass verification. This repository reproduces saved
results and does not include the private stellar solver.

Please consult LICENSE-NOTICE.md for reuse permissions. Scientific citation
metadata is in CITATION.cff.
