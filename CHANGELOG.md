# Release history

## 1.0.0 — 2026-10-05

First public release of the saved numerical data and data-only reproduction
package for the associated composition g-mode article.

- One command regenerates 9 numbered figures (11 PNG/PDF asset pairs) and
  8 tables, together with plotted-coordinate records and verification hashes.
- Includes equilibrium, composition, buoyancy, full-GR mode and reaction-limit
  data, the DD-ME2 comparison, and the published tidal estimates.
- Preserves full-precision saved inputs and documents plot processing,
  endpoint conventions and proof-corrected table numbering.
- Includes a manual, data dictionary, provenance, citation metadata and
  9 regression tests. Fresh-install checks on two desktops passed.

The numerical payload and reproduction code are unchanged from the reviewed
candidate. Solver source, private correspondence and internal research records
are excluded. See LICENSE-NOTICE.md for the rights notice.
